# TaskUni — Gerenciador de Tarefas Acadêmicas

## 📚 Sobre o projeto

O TaskUni é uma aplicação web desenvolvida com o objetivo de facilitar a organização e o acompanhamento de tarefas acadêmicas. O sistema permitirá que estudantes cadastrem atividades, consultem seus prazos e acompanhem o andamento de seus trabalhos e estudos em um único ambiente.

## 🎯 Problema que o projeto resolve

Estudantes universitários frequentemente precisam lidar com diversas atividades, trabalhos, provas e prazos de entrega. A falta de organização pode dificultar o acompanhamento dessas responsabilidades e ocasionar esquecimentos ou atrasos.

O TaskUni busca solucionar esse problema por meio de uma plataforma simples e intuitiva que centraliza as tarefas acadêmicas, facilitando seu gerenciamento.

## 👥 Público-alvo

O sistema é destinado a estudantes universitários que desejam organizar suas atividades acadêmicas, acompanhar prazos e controlar o status de suas tarefas.

## ⚙️ Requisitos funcionais

O sistema contará inicialmente com os seguintes requisitos funcionais:

- **RF01 — Cadastro de tarefas:** permitir o cadastro de tarefas com título, descrição, disciplina e prazo de entrega.
- **RF02 — Consulta de tarefas:** permitir a visualização das tarefas cadastradas e de suas respectivas informações.
- **RF03 — Atualização de status:** permitir alterar o status das tarefas para pendente ou concluída.

## 🛠️ Tecnologias previstas

O desenvolvimento do TaskUni prevê a utilização das seguintes tecnologias:

- **Java:** linguagem utilizada no desenvolvimento do backend.
- **Spring Boot:** framework para construção da aplicação backend e da API REST.
- **Maven:** ferramenta para gerenciamento de dependências e construção do projeto Java.
- **HTML5:** estruturação das páginas da aplicação.
- **CSS3:** estilização e organização visual da interface.
- **JavaScript:** implementação das interações da interface e comunicação com a API.
- **Git e GitHub:** controle de versão e armazenamento do código-fonte.

## 📌 Escopo inicial

A primeira versão do TaskUni priorizará as funcionalidades de cadastro, consulta e atualização do status das tarefas acadêmicas. Novas funcionalidades poderão ser incorporadas posteriormente, conforme o andamento do projeto e a disponibilidade de tempo da equipe.

Projeto desenvolvido para a disciplina **Programação para Internet**, como atividade prática do segundo bimestre, com foco em programação orientada a objetos, desenvolvimento web e integração entre frontend e backend.
